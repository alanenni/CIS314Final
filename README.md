You need all 3 files in a folder in order for the code to work. Then use the "final" file to run the game

This is a continuation of my midterm, I turned the midterm into a class that has 2 methods. The first method generates the 
number for the user to guess and the difficulty. The second method is to check if the guess was right or wrong. 

The second file "gui" creates a graphical user interface for the game. It creates a gui class for the game, and has lots is made of many methods
that do things such as setting the difficulty, starting the game, showing/hiding numbers, and checking if the user entered a valid input.

The third file "final" brings it all together by importing the other 2 files, starting the gui and setting up the game
